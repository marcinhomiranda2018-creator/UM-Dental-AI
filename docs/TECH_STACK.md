# Stack Tecnologica-UM Dental AI
### Objetivo
Definir a arquitetura tecnologia do UM Dental AI, especificando as tecnologias que serao ultilizadas no desenvolvimento da plataforma, garantindo segurança, escalabilidade, desempenho e facilidade de manutençao

### Frontend
-Next.js para estruturar a aplicacao wed
-React para criar as interfaces e componentes 
-TypeScript para deixar o codigo mais seguro e organizado 
-Tailwind CSS para construir uma interface responsiva e consistente em computador, tablet e celular

### Backend 
-Linguagem, dois pontos. Python, como linguagem principal.
-Framework
-FastAPI para desenvolvimento da API, como desempenho e documentaçao automatica 
-ORM
-SQLAIchemy para comunicaçao com o banco
-Validaçao de dados, Pydantic
-Autenticaçao, JWT para autenticaçao segura dos usuarios
-Banco de dados 
-Tecnologia: PostgreSQL
-Estrutura: Usuarios, clinicas, dentistas, paciente, casos, arquivos, produçao, financeiro, estoque e agenda
-Recursos: Controle de versoes, historico completo, backup automatico, recuperaçao de dados e criptografia
